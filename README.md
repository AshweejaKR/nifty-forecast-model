# Tiny GPT From Scratch (Learning Project)

## Goal
Build a tiny GPT language model from scratch for learning purposes.

## Architecture
1. Dataset
2. Tokenizer
3. Data Loader
4. Embedding Layer
5. Positional Encoding
6. Transformer Block
   - Multi-Head Self Attention
   - Feed Forward Network
   - LayerNorm
7. Output Head
8. Training Loop
9. Text Generation

## Tech Stack
- Python
- NumPy
- PyTorch
- Matplotlib

## Learning Outcome
- Understand GPT internals
- Train a small language model
- Build inference pipeline
- Learn transformer architecture
